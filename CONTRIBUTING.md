# Contributing

Thanks for your interest in improving this public IBRAMIND demonstrator.

## Good public contributions

Contributions may improve:

- Documentation and examples
- Synthetic/open test fixtures
- Reproducible evaluation
- Error handling
- Accessibility and developer experience
- Security hardening that can be discussed publicly

## Do not submit

Do not add:

- Customer, bidder, supplier, employee, or other personal/confidential data
- API keys, tokens, passwords, private keys, or production environment files
- Private IBRAMIND source code or proprietary enterprise workflows
- Production infrastructure details that create security risk
- Third-party copyrighted/confidential documents without permission

## Pull requests

Keep changes focused and explain:

1. The problem being solved
2. What changed
3. How it was tested
4. Any security, privacy, procurement, or engineering limitations

Public contributions do not change the commercial boundary described in `COMMERCIAL.md`.

For commercial partnerships or paid pilots, use https://ibramind.com or contact founder@ibramind.com.
